### Quick Report

Microsoft is reshaping Copilot into a hub that sits across a user\'s workday instead of waiting to be opened as a standalone chatbot. Satya Nadella\'s description covers a package that connects Office, Teams, the Today information feed, the Autopilot enterprise agent, and the Code development tool.
<!-- more -->

Home will bring Chat and Cowork together, while an Office area embeds Word, Excel, and PowerPoint. Code is aimed at creating applications inside an organization\'s tenant, and Microsoft says the more intensive agent features will use metered billing that users must enable. The company is presenting this as a work-platform strategy, distinct from making Copilot a component of the Windows operating system.
