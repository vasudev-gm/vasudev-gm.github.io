### Quick Report

Mozilla has released Firefox 161.0 with per-site controls for its built-in VPN and a selection of classic themes in the Add-ons Manager. The release also adds a keyboard shortcut to copy the current page URL, though users must configure the shortcut themselves.
<!-- more -->

The available themes include solid-color options, an OLED theme, and the Proton theme from earlier Firefox releases. Other changes include fixes for restored sessions with missing tabs and full-screen windows obscured by the Windows taskbar, plus improvements to bookmark loading on macOS and imported Chrome history suggestions.
