### Quick Report

IBM and Arm have announced a next-generation processor intended to bring native Arm software support to future IBM Z and LinuxONE systems. The design will allow organizations to run Arm-native Linux environments alongside z/OS and Linux workloads while retaining enterprise security and reliability features.
<!-- more -->

Built on a 2 nm process, the processor is planned to include 11 high-performance cores running above 5.7 GHz, AI inference accelerators, a data-processing unit for I/O, and a large cache architecture. IBM says each core can execute Arm and IBM Z instruction sets, giving the platform a dual-architecture capability without separate Arm and IBM core complexes.
