### Quick Report

Windows 11 is adding per-app controls for microphone, location, and camera access. The change gives users more granular control over which applications can use sensitive hardware and location data.
<!-- more -->

More precise permissions can make it easier to limit unnecessary access without disabling a capability for the entire system. Users should still review existing permissions after the update and understand how desktop, web, and packaged applications are handled.
