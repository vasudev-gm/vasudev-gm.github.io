### Quick Report

Google has started rolling out the November update for Googlebook, and the biggest change is how much memory the platform on-device AI stack takes up. On the Acer Googlebook 14, ASUS Googlebook 14, and Lenovo Googlebook 15, Google release notes say it has improved memory usage for on-device AI to make multitasking more stable on 16 GB devices.
<!-- more -->

The update appears to stem from improved memory management in the NPU driver, which can reclaim between 3 GB and 6 GB of system RAM and let Chrome borrow memory back when it needs more headroom. The reported memory gain is substantial on 16 GB machines, and the update also brings the November 1 security patch plus fixes for Bluetooth audio, external USB microphones, and a long list of general reliability issues.
