### Quick Report

Beat Saber has been upgraded to Steam Frame Verified status, a notable milestone as Valve continues preparing its upcoming VR headset for launch. The change suggests the game is now considered compatible with the platform in standalone mode, running on the headset\'s internal Arm-based processor instead of requiring a PC.

The update, first noticed in SteamDB, moved the title from unsupported to fully verified, including correct controller layout support. That matters because Steam Frame verification is a practical checkpoint for launch readiness: it signals that key VR titles can run smoothly on the hardware and software stack Valve expects to ship.
