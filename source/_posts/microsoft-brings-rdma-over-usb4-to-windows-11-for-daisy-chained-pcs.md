### Quick Report

Microsoft is extending RDMA support to USB4 on Windows 11, opening the path for low-latency links between daisy-chained PCs and compatible devices. The feature can help workloads that need fast local transfers without relying only on Ethernet or Thunderbolt-style networking interfaces.
<!-- more -->

RDMA bypasses much of the normal software and CPU path used for network communication, reducing latency and host overhead. Using it over USB4 could simplify compact workstation connections, external compute arrangements, and specialized development setups.

Wider usefulness will depend on hardware support, driver quality, and whether consumer and professional USB4 implementations expose the necessary features consistently. Still, the addition makes direct PC-to-PC connectivity more flexible for users with bandwidth-sensitive applications.
