### Quick Report

An open-source project led by members of Heroic Games Launcher is aiming to bring Xbox Game Pass titles to Linux and macOS. The work is still early, but the team says it has already made progress on authentication, downloads, and runtime support for launching Microsoft titles outside Windows.
<!-- more -->

The project is built around compatibility layers and reverse-engineered runtimes that could one day make Game Pass titles feel much closer to native installs on Linux. If the effort succeeds, it would expand the reach of Microsofts subscription library and give Linux gamers more practical access to titles that have long been tied to Windows.
