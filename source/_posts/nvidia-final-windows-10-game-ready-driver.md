### Quick Report

NVIDIA plans to release its final GeForce Game Ready and Studio driver supporting Windows 10 in October 2026. Beginning in November, new game optimizations and feature updates will target newer Windows versions, marking the end of regular driver support for an operating system that reached Microsoft end of support in October 2025.
<!-- more -->

NVIDIA extended Windows 10 driver support for an additional year because many GeForce users still rely on the platform. Although feature and game support will stop, NVIDIA says critical security driver updates will continue through October 2029, giving users additional time to transition to Windows 11 or another supported environment.
