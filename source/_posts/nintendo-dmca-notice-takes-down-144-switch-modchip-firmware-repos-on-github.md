### Quick Report

Nintendo has sent a DMCA notice that led GitHub to disable 144 repositories hosting Nintendo Switch modchip firmware. The takedown was aimed at a fork network tied to a repository called Picofly, and it reflects a continued effort to clamp down on tools used to bypass console protections and run unofficial software.
<!-- more -->

The move is notable because it signals Nintendo is not only targeting the modchip software itself, but also the broader repository ecosystem around it. The company’s complaint reportedly argued that the forks were materially the same as the original and therefore equally infringing, which is a common legal strategy when a project has a large fork network.

The bigger issue is that these tools are part of a broader cat-and-mouse game between console makers and modding communities. Even when a technique is limited to older hardware like the original Switch, the takedown underscores how active enforcement is in a space where software piracy and custom firmware remain a constant pressure point for platform owners.
