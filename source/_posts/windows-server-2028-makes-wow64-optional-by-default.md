### Quick Report

Windows Server 2028 will no longer include the WoW64 compatibility subsystem in its default installation. Microsoft says administrators can still add the feature on demand, so 32-bit applications will require an extra step rather than being permanently unsupported.
<!-- more -->

Microsoft presented the change as part of a broader secure-by-default effort, reducing support for legacy components and limiting exposure to 32-bit malware. Windows 11 is unaffected, and Microsoft has not announced plans to remove 32-bit app support from its client operating system.
