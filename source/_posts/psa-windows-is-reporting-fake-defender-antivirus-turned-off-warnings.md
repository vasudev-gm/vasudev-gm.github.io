### Quick Report

Users on Windows 11 and Windows Server are reporting fake "Microsoft Defender Antivirus is turned off" notifications even though the real antivirus protection is still active. The warnings appear after booting or shortly after startup, and Microsoft has acknowledged the issue after the latest Defender update began triggering false alerts.
<!-- more -->

The problem affects systems running the recent Defender update and seems tied to a notification bug rather than a real security state change. In practical terms, the protection remains on, but the system is still surfacing a misleading scare message that can cause confusion and unnecessary concern for anyone monitoring security alerts.
