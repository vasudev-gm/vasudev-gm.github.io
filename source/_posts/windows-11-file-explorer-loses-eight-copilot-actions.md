### Quick Report

Microsoft is retiring eight OneDrive-linked Copilot actions from the Windows 11 File Explorer context menu: Summarize, Create FAQ, Compare Files, Ask a question, Explain image, Explain images, Compare images, and Extract text. The actions appear for OneDrive-linked files, rather than representing a removal of Copilot from File Explorer as a whole.
<!-- more -->

Microsoft describes the change as simplifying the context menu. Reporting says a staged removal will begin in mid-November 2026 and finish by December; users can still reach Copilot features through Ask Copilot, File Explorer Home, or the OneDrive activity center.
