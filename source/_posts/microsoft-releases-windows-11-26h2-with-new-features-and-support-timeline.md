### Quick Report

Microsoft has released Windows 11 version 26H2, bringing a collection of feature changes across File Explorer, Search, accessibility tools, and the Start menu. File Explorer gains summarization and broader archive support, while Search is designed to favor local files, recognize partial app names, and handle typing mistakes more gracefully.
<!-- more -->

The release also adds new Magnifier controls, a Braille Viewer for Narrator, expanded voice commands on Copilot+ PCs, and more Start menu and Taskbar layout choices. For users already on Windows 11 24H2 or 25H2, the transition can use a small enablement package because much of the underlying functionality has arrived through earlier updates. Home and Pro receive 24 months of servicing, while Enterprise and Education editions receive 36 months.
