### Quick Report

AMD has published Radeon Software Adrenalin 26.11.2 as a WHQL graphics-driver release. The package updates Radeon software for the latest supported games and applications and brings AMD\'s normal collection of stability fixes and compatibility improvements.
<!-- more -->

Users should review the bundled release notes before upgrading because WHQL packages can include both broad bug fixes and new game-specific optimizations. Radeon owners can also use the AMD Software interface to check whether the update is being offered for their GPU and operating-system combination.

The 26.11.2 release follows AMD\'s monthly driver cadence and gives users a certified update without moving to a separate hotfix branch.
